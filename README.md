# GarageYard для Linux

Выделенный сервер для «Стройки», «Автопарка № 7» и «Химлаборатории». Игроки входят через раздел «Подключиться по сети» в гараже.

## Обновление из полного выпуска 1.0.6

Если служба установлена из репозитория, выполните на сервере из каталога клона:

```bash
git pull --ff-only && sudo bash ./update.sh
```

Команда скачает сервер 1.0.6 с GitHub и перезапустит работающий матч. Можно также обновиться из локальных файлов. Положите рядом `GarageYard-LinuxServer-1.0.6.tar.gz` и `SHA256SUMS.txt` из каталога Releases и укажите путь к архиву.

```bash
sudo bash update-from-archive.sh /путь/к/Releases/GarageYard-LinuxServer-1.0.6.tar.gz
```

Скрипт проверяет SHA-256 и распаковывает новую версию рядом с действующей. Работающая служба перезапускается с прежними настройками лобби и данными. Предыдущий каталог игры сохраняется для отката. Для совместного матча используйте Windows 1.0.6 и Android 1.0-beta.1.6 (код 7).

## Стройка в версии 1.0.3

Кран открывает груз на 10:00. На вынос бутылки через проходную есть пять минут. При истечении срока вся группа видит «GAME OVER». Сервер определяет победителя при пересечении порога с бутылкой. Упавший под карту получает «200».

Каждый начинает с ножом и заряженным ПМ. Конверты приносят за раунд 3 900 монет на четверых. Обрез стоит 375, АК — 750. Запасные пачки патронов стоят 75 за 90 пистолетных, 125 за 60 автоматных и 65 за 10 дробовых. Для просмотра подборов и фактических покупок выполните `journalctl -u garageyard -g ConstructionEconomy`.

## Установка

Для Ubuntu 24.04 x86-64 с systemd, Python 3, Bash, Git и curl. Установщик загружает сервер из публичного релиза GitHub. Из родительского каталога выполните одну команду.

```bash
git clone --depth 1 https://github.com/blogerandrey-ux/garageyard-server.git && bash garageyard-server/install.sh
```

Установщик скачивает `GarageYard-LinuxServer.tar.gz` из [последнего релиза](https://github.com/blogerandrey-ux/garageyard-server/releases/latest) и сверяет его с `SHA256SUMS`. Вход в GitHub не требуется. Для установки своего архива задайте `GARAGEYARD_ARCHIVE=/путь/к/GarageYard-LinuxServer.tar.gz`. Серверные данные устанавливаются в `/srv/garageyard`. Чтобы выбрать другой диск, передайте `GARAGEYARD_HOME=/путь/к/данным`. Каталог должен быть доступен на чтение и проход системному пользователю `garageyard`. Скачивание и распаковка происходят на выбранном диске.

Архив игры и патчи скачиваются через aria2 в несколько частей, до восьми соединений одновременно. Если aria2 нужен впервые, скрипт сам установит пакет. При обрыве повторите `bash garageyard-server/install.sh` из родительского каталога или ту же команду обновления под той же учётной записью. Скрипт продолжит с сохранённых частей и проверит SHA-256 перед установкой.

Установщик спрашивает карту, название, доступ, видимость и адрес общего каталога. Для закрытого лобби пароль вводится без эха. Игра принимает его в поле «Пароль закрытого лобби». На сервере хранится производный ключ в файле с ограниченными правами. Для входа клиент подписывает проверочное значение соединения.

## Управление

```bash
sudo garageyard
```

Из меню можно запустить или выключить сервер, сменить карту, пароль, видимость, название и адрес каталога. Скрытый сервер доступен по прямому игровому адресу. Смена пароля действует на следующие подключения. Изменения видимости и доступа подхватываются во время матча. Смена карты перезапускает процесс и разрывает текущие подключения. «Выключить» также отключает автозапуск, «Запустить» возвращает его.

После завершения матча выделенный сервер показывает результат восемь секунд, затем открывает ту же карту для следующего раунда. Журнал доступен через `journalctl -u garageyard -f`.

## Автоматический поиск

В локальной сети сервер отвечает на широковещательный запрос. Для общего интернет-списка установите каталог на одном хосте с постоянным публичным IPv4.

```bash
bash garageyard-server/install.sh directory
```

Укажите адрес этого хоста в настройках каждого игрового сервера и один раз в `Unreal/Config/DefaultGame.ini` клиентской сборки. Например, для каталога с условным адресом конфигурация выглядит так.

```ini
[GarageServers]
DirectoryEndpoint=203.0.113.10:14080
```

Игровые хосты отправляют отметку присутствия каждые 10 секунд. Каталог подтверждает обратную доступность отправителя и удаляет истёкшие записи через 35 секунд. Клиент запрашивает перечень и показывает только серверы, ответившие на игровой запрос. Список обновляется, пока открыт сетевой экран.

| Хост | Входящий UDP | Назначение |
| --- | --- | --- |
| Игровой сервер | 7777 | Игра и проверка пароля |
| Игровой сервер | 14079 | Ответы на запросы списка |
| Общий каталог | 14080 | Регистрация и поиск |

За NAT игровому хосту нужны доступные извне порты игры и поиска. Для регистрации используется адрес и порт источника UDP, поэтому проброс порта поиска должен сохранять номер исходящего порта. Установщик оставляет сетевые правила под управлением администратора.

## Сборка релиза из исходников

На Linux-машине сборки нужны **полный проект GarageYard** и исходная сборка Unreal Engine 5.8.4 с поддержкой LinuxServer. В проекте должна быть цель `GarageYardServer.Target.cs`. Подготовьте движок и соберите UnrealEditor для cook. Упаковщик положит архив и контрольную сумму в `Unreal/Saved/LinuxRelease` внутри проекта.

```bash
UE_ROOT=/путь/к/UnrealEngine bash garageyard-server/build.sh /путь/к/Unreal/GarageYard.uproject
cd /путь/к/Unreal/Saved/LinuxRelease
gh release create server-v1 GarageYard-LinuxServer.tar.gz SHA256SUMS --repo blogerandrey-ux/garageyard-server --title 'GarageYard Linux Server'
```

Клиент и сервер должны быть собраны из совместимых версий проекта. В репозитории установщика хранятся инструменты развёртывания. Игровые ресурсы поставляются в архиве релиза.
